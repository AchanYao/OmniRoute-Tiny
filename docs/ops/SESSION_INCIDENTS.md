# Session incidents

Historical accidents that produced the cross-session git rules in [`AGENTS.md`](../../AGENTS.md).
Keep this file for context; do not copy the dates back into agent instructions.

| Date                   | Issue / context                                                | What happened                                                                                                                                                                                                                                                                                  | Rule it produced                                                                                                                                            |
| ---------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-06-05, 2026-06-13 | Shared main checkout                                           | `git checkout` / branch switch on the shared working tree discarded another session's uncommitted work and yanked the branch out from under a running session.                                                                                                                                 | Hard Rule #19 — every task gets its own worktree; never develop on the shared checkout.                                                                     |
| 2026-06-25             | Worktree inside the TypeScript include glob                    | A worktree outside a `tsconfig.json` / `.dockerignore` exclude leaked into `next build`. `include: **/*` globbed ~70× the codebase and OOM'd the build.                                                                                                                                        | Keep worktrees in a directory already excluded from the TS/build glob (today: `.claude/`, `.worktrees/`). Never park one at repo-root.                      |
| 2026-07-02             | `#5923` / `#2296`                                              | `git stash pop` leaked a `quotaCache` change from `#5923` into the unrelated `#2296` worktree. `git stash` uses the **shared repository object store**, not the per-worktree working tree. The same class reincided through a **subagent** that did not inherit the stash ban.                 | Hard Rule #22a — never `git stash` / `stash pop` anywhere, including inside worktrees and subagents. Put the ban in every subagent prompt that touches git. |
| 2026-07-04             | v3.8.40 / v3.8.41                                              | A parallel campaign advanced the frozen `release/vX.Y.Z` by 34 commits mid-run, forcing a full CHANGELOG re-reconciliation.                                                                                                                                                                    | Hard Rule #21 — release-freeze is a coordination signal; campaign workflows must not merge into the frozen branch.                                          |
| 2026-07-31             | [#9043](https://github.com/diegosouzapw/OmniRoute/issues/9043) | `ln -s` of `node_modules` into a worktree. Turbopack rejected the symlink (`Symlink [project]/node_modules is invalid, it points out of the filesystem root`). Typecheck, lint, and tests still passed; the error names "filesystem root", not the worktree, so it read like a Next/build bug. | Hard-link `node_modules` with `cp -al`. Never symlink it.                                                                                                   |
